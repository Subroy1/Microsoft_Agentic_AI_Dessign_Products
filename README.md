# Microsoft_Agentic_AI_Dessign_Products

This repository contains a collection of projects and demos focused on Agentic AI, systems thinking, design, and impact.

## Included projects

- [n8n_mcp](./n8n_mcp/) - Research agent workflow with MCP server in n8n

## About this project

The `n8n_mcp` project demonstrates how to connect an AI agent to an MCP server and use external tools to perform research. It combines:

- n8n workflows
- Model Context Protocol (MCP)
- Google Gemini
- SerpAPI-powered web search
- Agent-driven research flows

This project is aligned with the broader goal of building practical, production-oriented agentic AI demonstrations.
